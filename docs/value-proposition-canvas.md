# VPC value proposition canvas

## ユーザーが

### 解決したい課題・欲求

行きたい場所を並べ、移動時間・営業時間・予算を踏まえて、実際に回れる旅行プランを決めたい

### 嬉しい（プラス）と感じること

場所を足したり順番を入れ替えたりすると時刻が自動で組み直され、無理のないプランがすぐ見える

### 困り・悩み（マイナス）と感じること

地図・メモ・チャットに情報が分散し、移動時間や営業時間の確認・転記に時間がかかる。変更のたびに後ろの予定を手で直し、営業時間外や時間超過の見落としが起きる

## 私たちが

### 何を提供するか

場所の登録・訪問順・滞在時間からタイムラインを自動生成し、制約チェックと自然言語での編集ができる旅行プランナー

### 嬉しいと感じてもらえるポイントは？

「フィレンツェを追加して」と頼むだけでプランが更新され、変更前後の差分と理由が表示される。時間・距離・金額はプログラムが計算するので、AIの推測を疑わなくてよい

### 困り・悩み（マイナス）を取り除くための工夫は？

移動時間と各地点の到着・出発時刻を自動で計算し、営業時間外・終了時刻超過・予算超過を警告する。候補が複数ある場所はAIが勝手に決めず、ユーザーに確認する
