# 価値仮説シート

## 取り組みたい社会課題・テーマ

**友人と旅行する人** の **旅行プランの作成・管理**

## ニーズと求める価値の仮説

### 対象者

行き先・訪問順・時間・予算を決めて同行者と共有する人

### ニーズ・欲求

行きたい場所を並べながら、移動時間・滞在時間・営業時間・予算を確認し、現実に回れる旅行プランを作りたい

### 課題・困りごと

場所探しは地図アプリ、予定はメモやスプレッドシート、相談はチャットと情報が分散し、移動時間や営業時間の確認・転記は手作業になる。場所を一つ足すたびに後ろの予定を全部計算し直す必要があり、営業時間外の到着や終了時刻の超過に気づきにくい。生成AIに丸投げすると時間や金額が正確でなく、結局自分で検証することになる

### 提供する価値

場所を選んで並べるだけで移動時間と各地点の到着・出発時刻を自動で計算し、営業時間・時間制約・予算の違反を教える。プランの変更は自然言語で頼めるが、時間・距離・金額の計算と検証は通常プログラムが行うため、AIの柔軟さと数値の正確さを両立する
