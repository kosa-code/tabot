## 1. 概要

旅行の予定を作成・編集・管理できるWebアプリケーション。


- AIがユーザーの希望を理解し、プランを提案・編集する
- 公開情報からデータを取得する
- 通常プログラムで計算・検証する

---

## 2. 背景・課題

友人・家族との旅行で計画をまとめる人は、次の状況に置かれている。

- 場所探しは地図アプリ、予定はメモやスプレッドシート、相談はチャットと、情報が目的ごとに分散している
- 移動時間や営業時間の確認と予定表への転記は手作業で、時間がかかる
- 場所を一つ足したり順番を変えたりすると、後ろの予定を全部計算し直す必要がある
- その結果、営業時間外の到着や終了時刻の超過に気づきにくい
- 生成AIに丸投げすると時間や金額が正確でなく、結局自分で検証することになる

---

## 3. 対象ユーザー

行き先・訪問順・時間・予算を決めて同行者と共有する人。

---

## 4. 提供価値

| 提供価値 | 実現する機能 |
|---|---|
| 場所を並べるだけで移動時間と到着・出発時刻が自動で決まる | 移動時間計算、update_schedule、タイムライン表示 |
| 営業時間外・終了時刻超過に事前に気づける | 制約チェック(警告表示) |
| 自然言語でプランを変更できる | OpenAI API + Function Calling |
| AIの変更内容が分かり、推測した数値を疑わなくてよい | 変更前後の差分と理由の表示、計算は通常プログラムが担当 |
| 候補が複数ある場所をAIが勝手に決めない | search_placesの結果をユーザーに提示して確認 |
| 旅行後のお金の精算まで一箇所で済む | 割り勘、経費管理、予算との差額表示 |
